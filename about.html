About MineBeacon.

A friendly, live-updating map of Minecraft server communities. Find a world, check its pulse, and see what it has been like through the day.

✦01 / LIVE SIGNAL

Counts that move with the community.

MineBeacon listens to Minetrack's public live feed for tracked server status and player counts. It updates as the upstream service sends new data, usually every few seconds. The feed can occasionally disconnect or lag, so a displayed number is a recent report, not a guarantee that a server is reachable from your own network.

⌁02 / DAILY HISTORY

Explore the last 24 hours.

For servers in Minetrack's tracked feed, the directory requests its 24-hour graph. Hover or tap the graph to inspect the reported player count at a specific time. Gaps and offline points are kept visible instead of being invented or smoothed over.

▧03 / SERVER DETAILS

More than an online badge.

MCSRVStat supplies additional status details such as version, MOTD, reported capacity, server icon, and any diagnostic message it provides. These checks are independent from Minetrack, so the two sources can disagree. When they do, MineBeacon shows the discrepancy.

⌕04 / OPEN DIRECTORY

Check a server address.

Use the Servers page to browse featured communities or check a public Java or Bedrock hostname. Any host can be checked through the status API, but only servers in Minetrack's feed have upstream live counts and day history. Profiles make that distinction clear.

☆05 / YOUR DEVICE

Favorites stay yours.

Saved favorites are stored in your browser's local storage. MineBeacon has no sign-in and does not send your favorite list to a server. Clearing browser data or switching devices will clear or change those local favorites.

DATA SOURCES & ATTRIBUTION

Open sources, clear limits.

Minetrack provides its public WebSocket live server feed and 24-hour history graph. MCSRVStat provides the optional server status API. Both services have their own availability, coverage, and update cadence. Minecraft is a trademark of Mojang Studios.
